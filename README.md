# Математическая статистика в Python: доверительные интервалы, проверка гипотез, ANOVA и корреляции

## О проекте
Учебный pet-project по математической статистике в формате воспроизводимого Jupyter-отчёта. В ноутбуке собраны расчёты, визуализации и интерпретации результатов: от описательной статистики и интервальных оценок до критериев согласия, таблиц сопряжённости, дисперсионного и корреляционного анализа. Проект демонстрирует практическое применение `scipy.stats`/`statsmodels` для задач DS/DA.

Ключевые темы:
- **Проверка гипотез и критерии согласия (SciPy/statsmodels):** параметрические проверки (среднее/дисперсия), goodness-of-fit (χ², Харке–Бера), однородность выборок.
- **ANOVA и анализ связей (SciPy/statsmodels):** однофакторный дисперсионный анализ (One-Way ANOVA), корреляционный анализ (Pearson/Spearman/Kendall), базовая регрессионная интерпретация (OLS).

Главный отчёт: `last_version_bdz.ipynb` (дополнительно: `last_version_bdz.pdf`).

## Цель и задачи
На сгенерированных/учебных данных отработать полный цикл статистического анализа:
- Рассчитывать выборочные характеристики (среднее, дисперсия, асимметрия, эксцесс и др.).
- Строить группировки, таблицы частот, гистограммы/полигоны частот и эмпирическую функцию распределения.
- Строить доверительные интервалы: для матожидания, дисперсии, разности матожиданий и отношения дисперсий.
- Проверять гипотезы о параметрах распределений (среднее/дисперсия), включая сравнение двух выборок.
- Применять критерии согласия (χ²) и тест Харке–Бера (Jarque–Bera).
- Проверять однородность выборок (в т.ч. критерий знаков и χ²-подход).
- Строить таблицы сопряжённости и проверять гипотезы независимости (χ² / `chi2_contingency`).
- Выполнять однофакторный дисперсионный анализ (one-way ANOVA / `f_oneway`).
- Анализировать связи между признаками: корреляции Пирсона/Спирмена/Кендалла, доверительные интервалы и проверка значимости (p-value).
- (Опционально) Давать регрессионную интерпретацию зависимости (линейная регрессия / OLS).

## Методы
- Описательная статистика, EDA и визуализация распределений
- Группировка данных, гистограммы/полигоны, эмпирическая функция распределения (ECDF)
- Доверительные интервалы (mean/variance, difference of means, ratio of variances)
- Проверка гипотез о среднем и дисперсии (t/F-распределения, p-value, критические области)
- Критерии согласия: χ², Jarque–Bera
- Проверка однородности выборок (в т.ч. критерий знаков)
- Таблицы сопряжённости и χ²-тест независимости
- Однофакторный дисперсионный анализ (ANOVA)
- Корреляционный анализ: Pearson/Spearman/Kendall + значимость и интервалы
- (Доп.) Линейная регрессия: `scipy.stats.linregress`, `statsmodels` OLS

## Как запустить
Команды для `bash` (Linux/macOS/WSL):
```bash
python -m venv .venv
source .venv/bin/activate

# Если requirements.txt есть в репозитории:
pip install -r requirements.txt

# Или базово:
pip install numpy pandas scipy statsmodels matplotlib jupyter

jupyter lab
# открыть last_version_bdz.ipynb
```
